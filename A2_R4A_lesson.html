📝 Exercise 4b · Read and answer — True or False?

Read the text. Then decide if the sentences below are True (T) or False (F).

My name is Marta and I live in a quiet area on the edge of the city. There isn't a big park, but there are some small green spaces near my flat. There are a lot of cafés and restaurants on the main street — I love them! There is a sports centre five minutes from my house, but there isn't a stadium. There are some nice shops, but there aren't any big shopping centres. There is a train station nearby, so it's easy to travel to the city centre. I really like my area — it's quiet but there are a lot of things to do!
1. Marta's area is in the city centre.
2. There are some cafés near Marta's flat.
3. There is a stadium near her house.
4. There aren't any shops in her area.
5. It's easy to travel to the city centre from Marta's area.

Clarify · There is / There are

📐 Form — Complete the grammar box

Type is, are, isn't, or aren't in each gap.

THERE IS / THERE ARE

💡 Remember: Use a/an with singular nouns · Use some/any with plural nouns
🐛 Spot the Mistake!

Each sentence has ONE mistake. Type the correct sentence, then click "Show correction" to check.

1. There are a castle in the city.
✅ There is a castle in the city. (singular noun → use "is")
2. There is some cafés near here.
✅ There are some cafés near here. (plural noun → use "are")
3. There aren't a hospital near my house.
✅ There isn't a hospital near my house. (singular → "isn't", not "aren't")
4. Are there some parks in your city?
✅ Are there any parks in your city? (questions use "any", not "some")
5. There is a lot of offices in the centre.
✅ There are a lot of offices in the centre. ("offices" is plural → use "are")
🔊 Pronunciation — Linked speech

In natural speech, words link together. Click "Show linking" to see how each sentence sounds.

1. There are some cafés.
🔗 /ðeərər/ — "there are" links: thererare
2. There isn't a hospital.
🔗 /ðeərɪznt ə/ — "there isn't a" links: there isn'ta
3. There are a lot of parks.
🔗 /ðeərər ə lɒtəv/ — all links: thererarealotof
4. There aren't any garages.
🔗 /ðeərɑːrənt eni/ — "aren't any" links: aren'tany
